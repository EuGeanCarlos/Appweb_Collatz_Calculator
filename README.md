# ⚙️ Conjectura de Collatz - Matemática Discreta (UEMA)

Projeto desenvolvido por **Gean Carlos** para a disciplina de **Matemática Discreta** no curso de **Engenharia da Computação (UEMA)**.

---

## 📘 Sobre o projeto

A **Conjectura de Collatz**, também conhecida como *3n + 1*, afirma que:

> “Escolha qualquer número natural n.  
> Se n é par, divida por 2; se for ímpar, multiplique por 3 e some 1.  
> Repetindo esse processo, sempre se chegará a 1.”

O algoritmo foi implementado em **JavaScript**, com interface moderna em **HTML + CSS**, inspirada nas cores do **Flamengo** (vermelho, preto e branco 🟥⚫⚪).

---

## 🧮 Exemplo da sequência

**Entrada:** 6  
**Saída:**  
6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1  

Cada passo é mostrado na tela com a operação aplicada.

## 📚 Explicação do desenvolvimento

1. Foi analisada a **Conjectura de Collatz** apresentada em aula.  
2. Implementou-se o algoritmo em JavaScript, com validação de entrada.  
3. O app exibe **cada etapa do cálculo**, explicando se o número é par ou ímpar.  
4. Foram realizados **vários testes** (30+) com diferentes números.  
5. O design foi personalizado com **cores do Flamengo**, simulando um app moderno.
